On Windows, skip this page. Open PowerShell (Start menu, type PowerShell) and paste this line: 
irm https://bur.io/doomsday/stats/windows/install.ps1 | iex
Or download install-mtgctl.cmd, double-click it and click Run when Windows asks; it is this and nothing more: 
@echo off
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://bur.io/doomsday/stats/windows/install.ps1 | iex"
pause
Either way an uploader is installed that sends new logs every 30 minutes, at logon, and when you close the client from a Play MTGO desktop shortcut. Nothing else to install. Everything it runs is four short scripts you can read first: install.ps1, mtgctl-upload.ps1, play-mtgo.ps1. Details and how to remove it.
